3. Translation models (folder "translator\models", Argos Translate packages)
======================================================================
Bundled pairs: ja->en, zh->en, ko->en, es->en, fr->en, de->en, ru->en, en->ja, en->es.
The models are distributed by the Argos Translate project (https://www.argosopentech.com/argospm/index/).
Each model folder contains a README.md with its exact credits. Summary:
  - zh, es, fr (v1.9) models are derived from OPUS-MT models by Jorg Tiedemann and Santhosh Thottingal,
    "OPUS-MT - Building open translation services for the World" (EAMT 2020), licensed CC-BY 4.0
    (https://creativecommons.org/licenses/by/4.0/). Converted to CTranslate2 format by Argos Translate.
  - ja, ko, de, ru, en->es models were trained by the Argos Translate project on public parallel data
    compiled by OPUS (https://opus.nlpl.eu/) (incl. CCAligned, WikiMatrix, OpenSubtitles, ParaCrawl, UNPC)
    and Wiktionary data via Wiktextract; ru models by Aleksey Kutashov. Argos Translate publishes these
    models for free redistribution; see each README.md for the dataset credits.
  - All model packages include sentence-splitting models from Stanza (Stanford NLP), Apache-2.0.
